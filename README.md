# Pawsitive Pet Academy Website Starter

Responsive static website using HTML, CSS and JavaScript.

## Open in VS Code
1. Extract the ZIP.
2. In VS Code choose **File → Open Folder** and select `Pawsitive_Pet_Academy_Website`.
3. Open `index.html` in your browser or use the Live Server extension.
4. No npm install or build step is required.

## Files
- `index.html` — home
- `about.html` — about the academy
- `courses.html` — all seven courses
- `course.html` — interactive individual course details
- `fees.html` — fee calculator and discounts
- `contact.html` — demonstration contact form
- `style.css` — styling and responsive layout
- `script.js` — course data and interactions

## Courses and fees
Canine Obedience Training, Pet Grooming, Animal Behaviour and Pet Business Management: R1,500 / 12 weeks each.
Puppy Care, Pet First Aid and Dog Walking: R750 / 6 weeks each.
Discounts: 1 course 0%, 2 courses 5%, 3 courses 10%, 4+ courses 15%.
